# <center>PC-TOOL</center>

<p align="center"><strong>一个不需要注册、不需要上传、不需要付费的在线工具箱。</strong></p>

<p align="center"><em>浏览器即是一切。</em></p>

---

我们做这个站点的初衷其实很朴素：**被逼的**。

想压缩一张图片，先看三十秒广告；想转一个音频格式，文件被悄悄传到了别人的服务器；想合并两个 PDF，弹窗告诉你"开通会员解锁批量处理"；好不容易找到个免费工具，用第三次就开始限速、限次数、限大小。于是我们干脆自己写一个——**完全免费、完全开源、不上传任何文件、不插一条广告**。不搞会员，不搞积分，不搞"每日免费 3 次"。你打开网页，它就是你的。

<br>

**它的原理说出来可能有点扫兴：没有服务器。**

整个站点是一堆纯静态的 HTML、CSS 和 JavaScript，托管在 CDN 上，没有任何后端接口参与你的文件处理。图片走 Canvas 与 WebCodecs 在本地解码编码，音频和视频靠编译成 WebAssembly 的 FFmpeg 在浏览器里跑，PDF 交给 pdf.js 解析与重排，加解密用浏览器原生的 Web Crypto，二维码、正则、哈希、进制转换这些更是纯计算。**你拖进去的每一个字节，从头到尾都没有离开过你的设备**，断网之后大部分工具照样能用。这也是为什么它敢说"隐私安全"——不是承诺，是物理上没有上传的通道。

<br>

**它能干的事情比你想象的多。**

目前收录了 **113 个工具**，覆盖图片压缩、裁剪、拼图、抠图、水印、格式互转，音频转码、剪辑、合并、变速、变调、BPM 检测，视频压缩、截帧、转 GIF、加水印、去水印、提取音轨，PDF 合并、拆分、压缩、加密、提取文字，以及 JSON 格式化、正则测试、JWT 解析、时间戳转换、Base64、URL 编解码、文本对比、Markdown 编辑、密码生成这类开发者日常，还有 BMI、汇率、房贷、倒数日、番茄钟、抽奖转盘、键盘测试这种生活小工具。它们按类别归置在同一个页面里，搜索框支持即时过滤，找到就能用，用完关掉，不留痕迹。除了这些纯前端工具，项目里还带了 B 站视频解析与 P2P 传输两个可选的辅助服务，属于少数需要网络的部分，独立部署，互不影响。

<br>

**语言上，我们没有做"国际化"，而是做了两套独立的站点。**

`cn.pc-tool.cn` 与 `en.pc-tool.cn` 是两份完整的静态目录，中文站用中文的措辞、中文的排版节奏和更适合中文阅读的字重与行距，英文站则重新写过文案与标点，而不是机器翻译后硬塞进同一套模板。两边工具一一对应，域名各自独立，访问哪一边都不会被强行跳转。站点内部再按设备分叉：桌面端与移动端各有一套布局，通过 UA、触控能力与视口宽度综合判断后自动进入对应版本，并且两端都会做反向校验，避免在 iPad 这类"既像电脑又像手机"的设备上反复横跳。深色与浅色主题都做了适配，选择会被记住，刷新时不会闪白。

<br>

**它不完美，但它诚实。**

没有登录，没有用户系统，没有数据留存，也就没有"你的历史记录"。所有处理都在当下这一秒发生，关掉标签页就什么都不剩。这既是它的局限，也是它存在的理由。代码全部开放在 [GitHub](https://github.com/Team-YM/pc-tool)，你可以自己部署一份，也可以把它改成你需要的形状。
