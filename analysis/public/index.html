API & 使用教程

使用 API 解析 B站视频

通过域名加 BV 号直接获取 B 站视频地址，接口会自动解析并跳转到可播放的视频资源。

按 BV 号解析GET BV*****
https://www.pc-tool.cn/analysis/bil/API=BV*****
支持分 P 参数GET /analysis/bil/API=BV*****&p=2
https://www.pc-tool.cn/analysis/bil/API=BV*****&p=2

使用教程

  1. 准备 BV 号从 B 站视频链接中找到 BV*****。
  2. 访问接口将域名和 BV 号拼接为 /analysis/bil/API=BV*****。
  3. 获取视频接口解析成功后会自动跳转到可播放的视频地址。
