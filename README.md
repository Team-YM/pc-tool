# PC-TOOL

> 免费在线工具集合 — 每一个功能都为效率而生，完全免费，为人民服务！

[pc-tool.cn](https://www.pc-tool.cn)

---

## 特色

- **完全免费，无任何广告. 无任何赞助商** — 不收一分钱，只为爱发电
- **纯前端处理** — 图片、音视频、文档等处理均在浏览器本地完成，不会上传到任何服务器，保护你的隐私
- **无需安装** — 打开浏览器即可使用，跨平台支持 Windows / macOS / Linux
- **PC + 移动端自适应** — 暗色现代化 UI，PC 端和手机端分别适配，自动切换
- **搜索直达** — 支持 `Ctrl+K` 快捷键搜索，快速找到所需工具

## 功能概览

### 图片处理
| 工具 | 说明 |
|------|------|
| 图片批量转格式 | JPG / PNG / WebP / GIF / BMP / PDF 互转，支持批量上传 |
| 图片压缩 | 批量压缩，可调节质量，有效减小文件体积 |
| 图片裁剪 | 自由比例裁剪，支持 1:1 / 4:3 / 16:9 等预设比例 |
| 图片拼接 | 多张图片横向或纵向拼接，可自定义输出分辨率 |
| 多图合成 GIF | 自定义帧率，将多张图片合成动画 GIF |
| 图片加水印 | 支持文字 / 图片 / 平铺水印，可调透明度与旋转角度 |
| 图片旋转 / 翻转 | 支持 90° 旋转、水平翻转、垂直翻转 |
| 图片调色 / 滤镜 | 亮度、对比度、饱和度、色相、模糊等参数调节 |
| 图片 DPI 转换 | 调整 DPI 分辨率，像素不变 |
| 智能抠图 | AI 去除图片背景，完全离线运行，隐私安全 |
| 图片转 Base64 | 拖入图片直接生成 Base64 编码字符串 |
| Base64 转图片 | 粘贴 Base64 字符串还原为图片 |
| 颜色格式转换 | HEX ↔ RGB ↔ HSL 互转 + 可视化调色板 |

### 音频处理
| 工具 | 说明 |
|------|------|
| 音频转格式 | MP3 / WAV / OGG / M4A 等多格式互转 |
| 音频转 OGG | 将 MP3 / WAV / FLAC / AAC 等转为 OGG |
| 音频压缩 | 可调节压缩质量，减小文件体积 |
| 音频截取 | 设定起止时间裁剪音频片段 |
| 音频合并 | 多段音频首尾拼接为一段 |
| 节拍器（BPM） | 精准节拍器，支持键盘空格快捷启停 |

### 视频处理
| 工具 | 说明 |
|------|------|
| 视频转格式 | 视频转换为 WebM 格式 |
| 视频压缩 | 支持 MP4 / WebM / MOV / AVI，可调画质与分辨率 |
| 视频提取音频 | 从视频中分离导出音频文件 |
| 视频转 GIF | 自定义帧率和输出尺寸 |
| 视频截取片段 | 设定起止时间截取视频片段 |
| 视频截图 / 取帧 | 播放到某一帧导出为图片 |
| B 站视频转 URL | 提取 B 站视频直链，适用于 VRChat 等场景 |

### 文档处理
| 工具 | 说明 |
|------|------|
| Word 与 PDF 互转 | 双向文档格式转换 |
| PDF 合并 | 多个 PDF 合并为一个，pdf-lib 纯前端实现 |
| 文件哈希计算 | 拖入文件计算 MD5 / SHA1 / SHA256 |

### 二维码
| 工具 | 说明 |
|------|------|
| 二维码生成器 | 输入文字 / 链接生成二维码，支持自定义颜色与 Logo |
| 二维码解析 | 上传二维码图片读取其中内容 |


更多功能还在持续添加中，欢迎大家提供反馈和建议！

## 技术特点

- **前端技术栈**：原生 HTML5 + CSS3 + JavaScript，无框架依赖，轻量高效
- **Canvas 背景动画**：粒子蠕虫 + 浮尘 + 连线效果，视觉体验独特
- **3D 卡片交互**：PC 端卡片支持鼠标跟随倾斜变换 + 光晕效果
- **响应式设计**：根据 User-Agent 自动跳转 PC 版 / 移动版页面
- **隐私优先**：所有文件处理在浏览器端完成，数据不离本地

## 项目结构

```
pc-tool/
├── index.html          # PC 端首页（工具网格 + 搜索 + 背景动画）
├── mobile.html         # 移动端首页（工具列表 + 滚动动画）
├── notice.html         # 更新公告时间线
├── CNAME               # 域名配置
├── favicon.png         # 网站图标
├── docs/               # 文档相关页面
├── agent/              # 托管跳转页面
└── tool/               # 各工具页面
    ├── common.css       # 工具页公共样式（暗色主题）
    ├── common.js        # 工具页公共脚本（背景动画 / 拖拽 / Toast）
    ├── lib/             # 第三方库（pdf.js）
    ├── image-*.html     # 图片相关工具
    ├── audio-*.html     # 音频相关工具
    ├── video-*.html     # 视频相关工具
    ├── qrcode*.html     # 二维码工具
    ├── word-pdf-convert.html  # 文档转换
    ├── pdf-merge.html   # PDF 合并
    ├── file-hash.html   # 文件哈希
    ├── color-convert.html     # 颜色转换
    ├── metronome.html   # 节拍器
    └── vrc-url.html     # B站视频转URL
```
