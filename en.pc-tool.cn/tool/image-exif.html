How removal works: When you export, the tool redraws the image pixels on a local canvas and re-encodes them. The new file contains only pixel data, with none of the EXIF, GPS or thumbnail metadata from the original file. Camera model, capture time and location are therefore removed completely. Everything happens in your browser, and the image is never uploaded to any server.
